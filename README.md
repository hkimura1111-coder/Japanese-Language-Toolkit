# Japanese-Language-Toolkit
A beginner Python project for analyzing Japanese text by character type, developed as part of my journey into NLP and Japanese language technology.
## Features
The current version can:
- Count Hiragana characters
- Count Katakana characters
- Count Kanji characters
- Count Latin letters
- Count Numbers
- Count Other Characters
- Count Total Characters
## Example
Input:
今日はいい天気です。ABC123!
Output:
Hiragana count: 5
Katakana count: 0
Kanji count: 4
latin count: 3
number count: 3
other count: 2
Total characters: 17
