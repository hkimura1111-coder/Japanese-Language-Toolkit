# Japanese-Language-Toolkit
A beginner Python project for analyzing Japanese text by character type, developed as part of my journey into NLP and Japanese language technology.
## Current Projects
### Character Analyzer
- Counts Hiragana
- Counts Katakana
- Counts Kanji
- Counts Latin letters
- Counts Numbers
- Counts Other characters
### Vocabulary Quiz
- Japanese-English vocabulary practice
- Correct/Wrong feedback
- Final score tracking
### Text Statistics Analyzer
- Total character count
- Unique character count
- Character frequency analysis
- Most common character detection
### Word Frequency Analyzer
- Word frequency counting
- Most common word detection
### File Text Analyzer
- Reads Japanese text from files
- Character frequency analysis
- Most common character detection
### Multi-File Text Analyzer
- Reads multiple text files
- Counts total characters
- Counts unique characters
- Finds the most common character
- Compares multiple documents
### Keyword Frequency Analyzer
Features:
- Keyword frequency counting
- Top keyword detection
- Dictionary-based text analysis
### Stop-Word Remover & Keyword Extractor
A simple keyword extraction tool that removes common stop words and identifies important keywords in text.
Features:
- Removes common stop words
- Extracts keywords from text
- Counts keyword frequencies
- Identifies the top keyword
